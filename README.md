# Drive3R project page

Static research project website for **Drive3R: Block-wise Streaming Geometric Foundation Models for Autonomous Driving**.

- Paper text, authors, figures, and experimental results follow the supplied AutoLab v13 manuscript.
- Only the first two video clips are presented: KITTI sequence 10 and Waymo 102436.
- Comparisons use looping GIFs. KITTI reconstruction is accelerated 4×; Waymo reconstruction retains its original speed. Both preserve the final ground-truth reveal with a three-second hold.
- Demo and benchmark tabs support keyboard navigation. Pause displays the final ground-truth reveal as a still image. Reduced-motion visitors see this static final frame by default.
- No build step, external JavaScript dependency, or remote font is required.

Open `index.html` to preview locally. For GitHub Pages, publish the root of the `main` branch. A local HTTP server enables clipboard and other browser features consistently.

Code release status follows the manuscript. This repository contains the project website and paper assets, not the model implementation.
